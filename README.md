# Digital Clock

A responsive digital clock built using HTML, CSS, and JavaScript.

## Features

- Live digital clock
- 12-hour format
- AM / PM indicator
- Live date display
- Dark / Light mode toggle
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons

## Project Structure

```bash
digital-clock/

```

## How to Run

1. Download or clone this repository.

```bash
git clone your-repository-link
```

2. Open the project folder.

3. Run `index.html` in any browser.

Or use **Live Server** in VS Code:
- Right click `index.html`
- Click **Open with Live Server**

## Functionality

### Clock
- Displays current hours, minutes, and seconds
- Updates every second using `setInterval()`

### Time Format
- Converts 24-hour format to 12-hour format
- Displays AM or PM automatically

### Theme Toggle
- Moon icon = Dark mode
- Sun icon = Light mode

### Responsive Design
- Desktop: Horizontal layout
- Tablet: Smaller clock boxes
- Mobile: Compact layout
- Small screens: Vertical stacked layout
